# ✨ Premium Happy Birthday Website

A responsive birthday website made with HTML, CSS and JavaScript.

## Features
- 3D-style animated balloons
- Animated confetti
- Surprise modal
- Built-in birthday melody using Web Audio API
- Responsive photo gallery
- Animated birthday message
- Wish button
- No frameworks required

## Customize
1. Open `index.html`.
2. Replace the birthday text/name with your own.
3. Put your own photos in `images/` and name them:
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
   - `photo4.jpg`
4. Upload everything to GitHub.
5. Go to **Settings → Pages → Deploy from branch → main → /root**.

The website also has fallback online images, so it still looks good before you add your own photos.

## GitHub Pages
After deployment, your URL will look like:

`https://YOUR-USERNAME.github.io/happy-birthday/`
